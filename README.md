# Fashion MNIST Image Classification using PyTorch
This project implements a Deep Learning model using PyTorch to classify clothing images from the Fashion-MNIST dataset.

## Dataset
Fashion-MNIST contains grayscale images of clothing items such as shirts, shoes, bags, and dresses.

Image size: 28x28 pixels  
Number of classes: 10

## Technologies Used
- Python
- PyTorch
- Pandas
- Scikit-learn
- Matplotlib

## Model Architecture

Input Layer → 128 Neurons → ReLU  
Hidden Layer → 64 Neurons → ReLU  
Output Layer → 10 Classes

## Training Details

- Optimizer: SGD
- Learning Rate: 0.1
- Epochs: 100
- Batch Size: 32

## Results

The model successfully learns to classify Fashion-MNIST images with good accuracy.
